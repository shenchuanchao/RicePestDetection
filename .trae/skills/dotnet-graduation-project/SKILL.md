你正在辅助一个.NET计算机专业毕业设计项目。严格按照以下八个阶段执行。

## 阶段 0：项目初始化

1. 读取 CODEBUDDY.md，确认当前项目的技术栈。
2. 检查项目目录结构是否符合规范。
3. 如果目录不存在，按 templates/project-structure.md 创建。
4. 确认技术选型：后端框架（MVC/Web API/Razor Pages）、ORM（EF Core/Dapper）、数据库、前端方案。
5. 输出项目初始化检查清单，等用户确认后进入下一阶段。

## 阶段 1：需求分析与选题

1. 根据用户提供的项目名称，输出需求分析文档草稿，包含：项目背景、研究意义、功能需求、技术选型理由。
2. 生成用例图（Mermaid 格式）和功能模块清单。
3. 输出需求分析文档，**停下来等用户确认**。

## 阶段 2：系统设计

1. 生成系统架构图（Mermaid 格式），标注各层职责。
2. 生成数据库E-R图（Mermaid 格式），标注表关系和字段。
3. 生成核心业务流程图（Mermaid 格式）。
4. 输出设计文档，**停下来等用户确认**。

## 阶段 3：开发环境搭建

1. 生成 .sln 和 .csproj 文件，配置目标框架版本。
2. 生成 appsettings.json 模板（连接字符串留空）。
3. 生成 Program.cs 骨架，注册基础服务。
4. 输出环境搭建命令（dotnet restore），等用户确认后执行。

## 阶段 4：核心功能实现

1. 按模块生成代码：
   - 实体模型（Models/）
   - DbContext 和迁移（Data/）
   - 服务层（Services/）
   - 控制器（Controllers/）
   - 视图（Views/，如适用）
2. 每个模块生成后，运行 dotnet build 验证编译。
3. **每个模块生成后停下来等用户确认**，不要一次性生成所有模块。
4. 关键业务逻辑必须附原理注释。

## 阶段 5：测试与调优

1. 为核心服务层编写单元测试（xUnit）。
2. 在 experiments/ 下创建测试记录文件。
3. 记录测试环境、测试用例、通过率、性能指标。
4. 如果测试不通过，分析原因并修复。

## 阶段 6：论文撰写

1. 根据系统设计文档和测试记录，生成论文各章节草稿。
2. 使用 templates/paper-outline.md 作为大纲。
3. 生成 Mermaid 图表插入论文对应章节。
4. 生成中英文摘要。
5. **所有 AI 生成的论文内容必须标注“待人工修改”**。

## 阶段 7：系统部署与演示

1. 生成 Dockerfile 和 docker-compose.yml。
2. 生成部署说明文档。
3. 输出演示操作步骤。
4. 生成答辩PPT草稿。

## 阶段 8：交付检查

1. 检查所有交付物清单：代码、数据库脚本、论文、演示材料、答辩PPT。
2. 检查代码是否可复现（README 中的 dotnet run 步骤能否跑通）。
3. 检查论文引用是否真实有效。
4. 输出交付检查报告，**停下来等用户最终确认**。
