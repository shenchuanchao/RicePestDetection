# 数据与安全红线

以下规则是硬性约束，AI 在生成任何代码或文档时必须遵守。

## 一、数据库红线

- 〖必须〗不生成 DROP TABLE、TRUNCATE 等破坏性 SQL。
- 〖必须〗EF Core 迁移由用户手动执行（dotnet ef database update），AI 只生成迁移文件不执行命令。
- 〖必须〗不编造表名、字段名。所有实体属性必须与需求分析中的数据结构一致。
- 〖推荐〗使用数据种子（Seed Data）填充初始数据，而不是手动执行 INSERT 脚本。

## 二、安全红线

- 〖必须〗不生成包含硬编码密码、API Key、连接字符串的代码。敏感配置通过 appsettings.json + User Secrets 管理。
- 〖必须〗所有用户输入必须经过模型验证（Model Validation）。
- 〖必须〗涉及身份认证的项目，必须使用 ASP.NET Core Identity 或 JWT，不自行实现加密逻辑。
- 〖推荐〗启用 HTTPS 重定向和 HSTS。

## 三、学术合规红线

- 〖必须〗不生成伪造的实验数据、结果或引用文献。
- 〖必须〗论文引用必须来自真实存在的文献，AI 生成的引用需人工验证（通过 DOI 或学术搜索引擎确认）。
- 〖必须〗代码实现必须真实可运行，不能只为“看起来完整”而生成占位代码。

## 四、文件安全

- 〖必须〗不执行任何删除文件的命令，由用户手动操作。
- 〖必须〗不生成任何 Git 命令（add/commit/push），由用户手动执行。
