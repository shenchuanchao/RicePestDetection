# 水稻病虫害检测系统 - 部署与演示说明

## 一、本地运行部署

### 1.1 环境要求

- .NET 8 SDK 或更高版本
- 操作系统：Windows / Linux / macOS

### 1.2 部署步骤

```bash
# 1. 还原依赖
dotnet restore

# 2. 构建项目
dotnet build

# 3. 运行项目（自动创建数据库并初始化种子数据）
dotnet run --project src/RicePestDetection.Web/RicePestDetection.Web.csproj
```

启动后访问：http://localhost:5094

### 1.3 默认账号

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | Admin@123456 |
| 普通用户 | user | User@123456 |

## 二、Docker 部署

### 2.1 使用 docker-compose（推荐）

```bash
# 构建并启动
docker-compose up -d --build

# 查看日志
docker-compose logs -f

# 停止
docker-compose down
```

访问：http://localhost:8080

### 2.2 使用 Dockerfile

```bash
# 构建镜像
docker build -t rice-pest-detection .

# 运行容器
docker run -d -p 8080:80 \
  -v uploads:/app/wwwroot/uploads \
  --name rice-pest-app \
  rice-pest-detection
```

## 三、ONNX 模型配置

系统支持两种运行模式：

### 3.1 真实模型模式

将训练好的ONNX模型文件放置在 `models/rice-pest-model.onnx`，系统启动时自动加载。

模型要求：
- 输入尺寸：224×224
- 输入通道：3（RGB）
- 输出类别：8（健康、稻瘟病、纹枯病、白叶枯病、稻曲病、稻飞虱、稻纵卷叶螟、二化螟）
- 输入归一化：像素值/255，均值117

### 3.2 模拟预测模式（默认）

当模型文件不存在时，系统自动使用模拟预测模式，基于图片路径生成稳定的预测结果，保证系统可演示运行。

## 四、演示操作步骤

### 4.1 系统首页展示

1. 启动系统，访问首页
2. 展示系统标题、统计数据卡片、常见病虫害列表

### 4.2 用户登录演示

1. 点击导航栏"登录"
2. 输入管理员账号 admin / Admin@123456
3. 登录成功后跳转首页，显示用户信息

### 4.3 病虫害知识库演示

1. 点击"病虫害知识库"
2. 展示7种常见病虫害卡片
3. 使用类别筛选（病害/虫害）和关键词搜索
4. 点击"查看详情"展示病虫害完整信息

### 4.4 图像检测演示

1. 点击"图像检测"
2. 上传一张水稻图片（拖拽或点击选择）
3. 点击"开始检测"按钮
4. 等待推理完成，展示检测结果（病虫害名称、置信度、防治建议）

### 4.5 检测记录演示

1. 点击"检测记录"
2. 查看历史检测记录列表
3. 点击"详情"查看完整检测信息
4. 可删除记录

### 4.6 数据统计演示

1. 点击"数据统计"
2. 展示累计检测次数、用户数等统计卡片
3. 展示近30天检测趋势折线图（ECharts）
4. 展示病虫害分布饼图（ECharts）

### 4.7 系统管理演示（管理员）

1. 点击"系统管理" → "用户管理"
2. 查看用户列表，可启用/禁用用户
3. 点击"系统管理" → "新增病虫害"，添加新知识
4. 点击"系统管理" → "操作日志"，查看系统操作记录

## 五、数据库说明

- 数据库类型：SQLite
- 数据库文件：`rice_pest_detection.db`（生成在项目运行目录）
- 首次运行自动创建数据库表和种子数据
- 无需手动执行迁移命令
